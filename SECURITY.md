# Security Policy

## Supported Versions

This project is preparing for an initial public release. Until a public
release tag is published, only the current default branch is considered
for security review.

After release tags are published, supported versions will be documented
here.

## Reporting a Vulnerability

Please do not report suspected vulnerabilities through public issues.

Use GitHub private vulnerability reporting / GitHub Security Advisories
for this repository when available. Reports should include:

- a description of the issue;
- affected files or commands;
- steps to reproduce;
- expected and observed behavior;
- any suggested mitigation, if known.

Do not include secrets, private keys, credentials, proprietary model
weights, or confidential data in a report.

This project does not currently publish a personal security contact
email. If GitHub private vulnerability reporting is not available, use
the repository owner's currently published contact channel if one is
later provided.
